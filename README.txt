هدية عيد ميلاد منّة — ملفات GitHub Pages

الملفات:
- index.html: موقع عربي متوافق مع الموبايل، بمفاجأة من 4 مراحل ورسائل عيد ميلاد.
- ضع ملف الموسيقى الاختياري باسم birthday-music.mp3 في نفس المجلد.

تشغيل الموسيقى:
1. اختر ملف MP3 تملك حق استخدامه أو مسموحًا لك باستخدامه.
2. أعد تسميته بالضبط birthday-music.mp3.
3. ارفعه بجانب index.html في مجلد النشر الصحيح على GitHub.
4. افتح الموقع واضغط زر «شغّلي الموسيقى». المتصفحات غالبًا لا تسمح بالتشغيل التلقائي قبل تفاعل المستخدم.

رفع الملفات من Android:
1. نزّل ملف ZIP واستخرج index.html.
2. افتح GitHub في Chrome وسجّل الدخول.
3. افتح المستودع الذي ينشر موقعك الحالي.
4. اضغط Add file ثم Upload files.
5. ارفع index.html وbirthday-music.mp3 (إن أضفته) إلى مجلد النشر الصحيح.
6. اضغط Commit changes، ثم انتظر حتى يتم تحديث GitHub Pages.

مهم:
- إذا كان في المستودع index.html قديم، نزّل نسخة احتياطية قبل استبداله.
- إذا كان النشر من مجلد docs أو فرع مختلف، ارفع الملفات إلى المكان المحدد في Settings > Pages.
- كلمة السر داخل HTML/JavaScript ويمكن لأي شخص فحصها؛ هي للمفاجأة فقط وليست حماية حقيقية.
- لم يتم تضمين أغنية تجارية في ZIP. أضف ملف MP3 تملك حق استخدامه أو استخدم تسجيلًا مرخصًا/خاليًا من الحقوق.
